## 3. Phase 0 build order

Each step ends on a check. The gate command is `uv run python scripts/gate.py --phase 0`; before step 1 it does not exist. Test names are proposals. A step is done when its check passes and its deliberate fault fails (RQ-62). The manual pilot (SPEC product RQ-117 to RQ-119) and the platform terms receipts (PL-32) are a parallel track, not build steps: they are owner actions, the gate reports them `unavailable` until each receipt exists, and the pilot exit receipt fixes the Phase 1 build list. Run records (RQ-55), the erasure canary test (RQ-42), the service split and the image digests (change 21, RQ-72b) and the Langfuse stack are Phase 1 work: the Phase 0 gate does not need them, because Phase 0 holds synthetic data in one service and writes traces as files.

1. Build the gate, the rule index and the doc lint: `scripts/gate.py`, `scripts/gate_registry.toml`, `scripts/rule_index.py`, `scripts/doc_lint.py`, the `PHASE` file, `scripts/design_check.py` from this design set and the CI job `design-check` (change 25). Check: `uv run pytest tests/test_gate.py tests/test_rule_index.py tests/test_doc_lint.py` passes; each deliberate fault of RQ-100 and RQ-101 exits 1; `gate.py --phase 0 --list` prints every Phase 0 id; the `design-check` job passes and, on a copy with one stale pin, fails. RQ-63, 100, 101, 103; PL-19. They come first because every later check reports through them.
2. Write migrations 002 to 005 and the roles (change 19; ports part, sections 4 and 5). Check: apply 001 to 005 to an empty database; `uv run pytest tests/test_schema.py` passes: `saathi_core` cannot update or delete `audit_log`, `saathi_model` cannot write approvals or `control.*`, `saathi_edge` can only insert into its four tables (`inbox`, `raw_text`, `rejected_inbound`, `alert_events`) and cannot read `raw_text`, every table has `household_id` and forced row-level security, the cross-tenant suite of RQ-109 passes and is shown to fail on a planted table with no policy, and `Store.tx` refuses a call with no household. RQ-56a, 95a, 38, 109, 110, 111a.
