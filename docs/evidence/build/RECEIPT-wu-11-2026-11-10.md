How it behaves: `PgVoiceStore.fixed` reads `voice_clips` for the key and language, takes the newest version that has `reviewed_by`, `reviewed_at` and `receipt_ref`, reads its file and compares the sha256. No row raises ClipMissing, rows without a complete review raise ClipUnreviewed, a damaged file raises ClipHashMismatch. `send_reply` sends the clip then the text; on any clip error (or a failed audio send) it sends the text alone, calls `owner_alert("clip_error")` and audits `clip_error` with a reason label.
